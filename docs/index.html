1. Cara Penggunaan Aplikasi KetikKu

Ikuti langkah singkat berikut untuk mengaktifkan KetikKu dan memaksimalkan fitur pengetikannya sehari-hari.

Aktivasi Awal Keyboard

  1. Buka aplikasi KetikKu lalu masuk ke tab Setelan.
  2. Tekan tombol 1. Aktifkan dan nyalakan KetikKu di setelan Bahasa & Masukan Android.
  3. Kembali ke KetikKu dan tekan 2. Pilih, lalu pilih KetikKu sebagai keyboard utama.
  4. Gunakan kolom Coba ketik di sini untuk langsung menguji pengetikan.

Kamus Pribadi (6 Folder Utama Permanen)

  • Kelola kamus satu tingkat (tanpa subfolder) dengan 6 folder utama permanen di urutan atas: Gmail, Nomor, Pribadi, Kata Sandi, Kredensial, dan Balasan Cepat (folder utama terlindungi agar tidak dapat diubah nama, dipindahkan, atau dihapus).
  • Entri di folder Kata Sandi dan Kredensial dijaga privasinya: tidak pernah muncul saat kolom kosong maupun saat mengetik awalan isinya, dan hanya muncul di bilah saran jika pintasannya diketik.
  • Mengetik pintasan tidak mengganti teks secara otomatis saat menekan Spasi/Enter — entri muncul di Kolom 1 & 2 bilah saran di semua kolom teks (termasuk kolom kata sandi) dan masuk saat chip diketuk.
  • Kolom pratinjau ketiga (di sebelah bilah alat) menampilkan pratinjau teks yang sedang dipilih (disorot) maupun karakter yang sedang diketik dengan ukuran huruf setara saran teks, gulir horizontal otomatis, serta pembatas kolom yang tegas dari atas hingga bawah.

Pemfolderan Otomatis & Papan Klip

  • Teks yang disalin tidak ditampilkan di bilah saran atas, melainkan tersimpan rapi di panel Papan Klip agar bilah saran tetap fokus pada kamus pribadi.
  • Alamat @gmail.com (≥ 20 karakter) yang disalin otomatis tersimpan ke folder Gmail.
  • Nomor telepon berawalan +62, 62, atau 08 (≥ 11 digit) yang disalin otomatis tersimpan ke folder Nomor.

Mode Floating, Tekan Tahan & Baris Bawah

  • Susunan baris bawah: tombol simbol Ω di paling kiri, diikuti Ctrl, tombol Spasi ekstra lega, tombol titik/koma (. / tahan ,), dan tombol Enter aksi editor.
  • Tombol hapus (⌫) menggunakan penghapusan terverifikasi agar dapat menghapus karakter apa pun secara andal, termasuk di aplikasi editor kode dan JSON.
  • Aktifkan Mode Melayang (Floating) dari ikon bilah alat atas dan geser pegangan untuk memindahkan posisi keyboard.

3. Pintasan Tombol Ctrl

KetikKu menyediakan tombol Ctrl langsung di baris bawah keyboard agar pengeditan teks secepat keyboard fisik.

1× Ketuk Ctrl = Aktif untuk 1 Kombinasi Huruf (mis. Ctrl+A, Ctrl+C, atau Ctrl+V) Otomatis Mati setelah 1 Huruf, Hapus, Spasi, atau Enter Ketuk Ctrl Lagi = Mati Seketika
Kombinasi Fungsi Keterangan
Ctrl + A Pilih Semua (Select All) Menyorot seluruh teks pada kolom aktif.
Ctrl + C Salin (Copy) Menyalin teks terpilih sekaligus mencatatnya ke Papan Klip KetikKu.
Ctrl + X Potong (Cut) Memindahkan teks terpilih ke papan klip.
Ctrl + V Tempel (Paste) Menempelkan salinan terbaru (mendukung teks panjang secara aman).
Ctrl + Z Urungkan (Undo) Mengembalikan perubahan pengetikan terakhir.
Ctrl + Y Ulangi (Redo) Mengulang kembali langkah yang baru di-undo.
Ctrl + B / I / U / F Pintasan Aplikasi Langsung Mengirim event tombol Ctrl+Huruf langsung ke editor, browser, atau terminal yang mendukung.

5. Sinkronisasi Otomatis Kamus Pribadi ke Perangkat

KetikKu bekerja 100% luring tanpa izin internet sehingga seluruh ketikan dan kata sandi tetap aman di perangkat Anda. Cadangan dipecah jadi 4 berkas di /storage/emulated/0/Documents/ tanpa membuat folder otomatis: ketikku_umum.json, ketikku_kata_sandi.json, ketikku_kredensial.json, dan ketikku_a2f.json. Anda bebas memilih subfolder lain di dalam Documents kapan saja. Sinkron hanya ke folder perangkat (timpa atas/bawah), tanpa Drive dan tanpa GitHub. Setiap perubahan langsung menimpa berkas terkait agar folder yang dihapus tidak kembali lagi. Seed A2F disimpan terenkripsi dan ikut dipulihkan ke perangkat lain tanpa perlu diisi ulang; kode A2F hanya muncul di bilah saran saat pintasannya diketik.

1 Berkas Tunggal & Jalur Bebas di Documents

Hanya mencadangkan Kamus Pribadi: daftar "folders" serta array "entries" dengan 6 field seragam (id, word, shortcut, folder, updatedAtMillis, deleted) tanpa field "language". Anda bebas memilih folder mana saja di dalam Documents/ atau kembali ke bawaan kapan saja.

Pemulihan Otomatis & Pengaman Entri Terbanyak

Saat aplikasi dibuka, KetikKu memulihkan penuh bila kamus lokal kosong atau bila berkas cadangan di folder Documents pilihan Anda lebih baru dengan entri lengkap (misalnya setelah diedit dengan AI). Berkas kosong atau terpotong dengan entri lebih sedikit tidak akan pernah menimpa kamus lokal — entri lokal tetap diselamatkan melalui penggabungan aman.

6. Variasi Instruksi AI untuk Edit Kamus JSON

Pilih variasi instruksi di bawah, klik tombol Salin Instruksi (atau klik langsung kotak kodenya), lalu kirim bersama berkas ketikku_*.json dari /storage/emulated/0/Documents/ (atau subfolder pilihan Anda) ke AI pilihan Anda.

Variasi 1 — Tambah Banyak Kalimat, Pintasan & Folder (Umum)

Format wajib seragam dengan 6 field pasti pada setiap entri dan folder satu tingkat (tanpa subfolder).

Struktur berkas JSON kamus pribadi KetikKu (ketikku_umum.json, ketikku_kata_sandi.json, ketikku_kredensial.json; semua berkas memakai struktur sama dan hanya berisi entri jenisnya):
{
  "updatedAtMillis": <timestamp_ms_terbaru>,
  "folders": ["Gmail", "Nomor", "Pribadi", "Kata Sandi", "Kredensial", "Balasan Cepat"],
  "entries": [
    {
      "id": "<id_unik>",
      "word": "<kalimat_atau_nilai>",
      "shortcut": "<pintasan_singkat_atau_kosong>",
      "folder": "<nama_folder_datar_atau_kosong>",
      "updatedAtMillis": <timestamp_ms_terbaru>,
      "deleted": false
    }
  ]
}
Aturan struktur:
1. Jangan sertakan field "language" atau field tambahan lain.
2. Setiap objek di "entries" wajib berisi 6 field: "id", "word", "shortcut", "folder", "updatedAtMillis", dan "deleted".
3. Folder hanya 1 tingkat (tanpa subfolder dan tanpa "/"). 6 folder utama: "Gmail", "Nomor", "Pribadi", "Kata Sandi", "Kredensial", "Balasan Cepat".
4. Entri di folder "Kata Sandi" dan "Kredensial" hanya tampil di bilah saran saat "shortcut"-nya diketik.
5. Pertahankan entri & "id" lama, lalu kembalikan 1 blok kode JSON valid.

Daftar kalimat, pintasan & folder yang ingin ditambahkan:
- [tulis daftar data atau folder di sini]

Variasi 2 — Template Chat Kerja, Bisnis & Customer Service

Meminta AI merapikan template balasan pelanggan ke dalam folder seperti Kerja, CS, atau Order.

Saya melampirkan file ketikku_umum.json. Tolong tambahkan daftar template balasan kerja/CS di bawah ke dalam array "entries" dan kelola foldernya tanpa menghapus entri lama.
Ketentuan format JSON:
- Root wajib: { "updatedAtMillis": <epoch_ms>, "folders": [...], "entries": [...] }
- Setiap entri wajib punya TEPAT 6 field ini (tanpa field opsional/tambahan dan tanpa "language"):
  { "id": "...", "word": "...", "shortcut": "...", "folder": "...", "updatedAtMillis": <epoch_ms>, "deleted": false }
- Masukkan template ke folder 1 tingkat (tanpa subfolder dan tanpa "/") misalnya "CS", "Order", "Kerja", atau "" jika umum, lalu daftarkan folder tersebut di array "folders".
- Buatkan "shortcut" singkat 2-4 huruf kecil tanpa spasi (mis. "slm", "inv", "rek", "kfm").
- Berikan output hanya berupa 1 blok JSON valid siap pakai.

Topik/kalimat balasan yang saya butuhkan:
- [tulis daftar balasan, info rekening, alamat, atau SOP di sini]

Variasi 3 — Ekstrak Otomatis dari Dokumen / Catatan / Materi

Tempelkan dokumen/catatan Anda bersama file JSON kamus agar AI memilih frasa penting dan menaruhnya di folder khusus.

Saya melampirkan dokumen/catatan dan file ketikku_umum.json.
Tugas Anda:
1. Ekstrak maksimal 25 kalimat, istilah penting, nomor/kode referensi, atau template frasa yang paling sering dipakai dari dokumen tersebut.
2. Tambahkan hasilnya ke "entries" pada ketikku_umum.json ke dalam folder 1 tingkat yang relevan (mis. "Materi" atau "Istilah", tanpa subfolder dan tanpa "/") tanpa mengubah entri lama.
3. Setiap entri wajib memiliki keenam field seragam:
   - "id": unik (mis. "doc_001")
   - "word": teks bersih siap tempel
   - "shortcut": huruf kecil 2-5 karakter atau ""
   - "folder": nama folder atau ""
   - "updatedAtMillis": timestamp milidetik terbaru
   - "deleted": false
4. Daftarkan folder yang dipakai di array "folders", jangan sertakan field "language", dan kembalikan JSON valid.

Variasi 4 — Rapikan, Gabung & Hapus Duplikat Kamus JSON

Membersihkan duplikat, menyeragamkan ke 6 field baku, dan menyinkronkan array folder secara rapi.

Tolong rapikan file ketikku_umum.json berikut dengan aturan:
1. Hapus entri duplikat yang isi "word"-nya persis sama (pertahankan yang "updatedAtMillis"-nya paling baru beserta "id" dan "folder"-nya).
2. Hapus field "language" dan "schemaVersion" jika masih ada.
3. Seragamkan setiap entri agar selalu memiliki 6 field: "id", "word", "shortcut", "folder", "updatedAtMillis", dan "deleted".
4. Pastikan semua folder 1 tingkat (tanpa subfolder dan tanpa "/"), lalu sinkronkan array "folders" tingkat atas agar berisi "Gmail", "Nomor" (jika ada), serta seluruh nama folder aktif.
5. Perbarui "updatedAtMillis" tingkat atas dan kembalikan 1 blok JSON valid.

Variasi 5 — Kelompokkan & Folderisasi Banyak Kamus ke Folder

Khusus untuk menyusun ulang atau menggabungkan ratusan kata, email, nomor, kode, atau banyak kategori ke struktur Folder satu tingkat yang rapi.

Tolong kelompokkan dan atur seluruh isi file ketikku_umum.json (serta daftar tambahan di bawah) ke dalam struktur Folder 1 tingkat yang terorganisir rapi.
Aturan pemfolderan:
1. Pertahankan/pisahkan alamat @gmail.com ke folder "Gmail" dan nomor telepon berawalan +62/62/08 ke folder "Nomor".
2. Kelompokkan entri lain ke folder bertema jelas tanpa subfolder dan tanpa "/" (contoh: "Kerja", "CS", "Alamat", "Belajar").
3. Urutkan array "folders" dengan "Gmail" dan "Nomor" paling atas (jika ada), lalu folder lainnya di atas entri tanpa folder.
4. Wajib pakai format seragam 6 field di setiap entri tanpa field opsional dan tanpa "language":
   {
     "id": "<pertahankan_id_lama_atau_buat_unik>",
     "word": "<teks_kamus>",
     "shortcut": "<pintasan_huruf_kecil_atau_kosong>",
     "folder": "<nama_folder_atau_kosong>",
     "updatedAtMillis": <timestamp_ms_terbaru>,
     "deleted": false
   }
5. Kembalikan hanya 1 blok kode JSON valid siap simpan ke /storage/emulated/0/Documents/ketikku_umum.json (atau folder pilihan Anda di dalam Documents).
